# Fruitless

An interactive fly courtship prototype. Static site: serve `dist/` with any HTTP server.

The simulation in `dist/model.js` uses 192 synthetic leaky integrate-and-fire units and seeded connectivity. It does not import MaleCNS data, simulate the original specimen, or claim biological validation. The interface shows actual model spikes, not randomly animated activity. Inputs and readout thresholds are engineering assumptions. Model provenance and references are also available in the interface.

All candidates use one illustrative photograph by Rolf Dietrich Brecher, CC BY 2.0, via Wikimedia Commons; attribution and source links appear in the site.

Next scientific milestone: import a versioned, documented MaleCNS courtship subnetwork and validate sensory encoding and readout using independent behavioural data and perturbations.
